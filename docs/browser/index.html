Description Shortener

V1.4 · Browser

Runs on your device. The first use downloads a verified model of about 7 GB and keeps it in this browser across app updates. Reopening the app loads that cached model. Clearing browser data or storage eviction can require another download. Use a computer with 24 GB RAM or more and a WebGPU-capable browser, such as current Chrome or Edge.

Load the model for AI shortening. Without it, you can get a quick source excerpt marked “May need review”. Your descriptions and files stay on this device.

110 characters maximum

Minimum 110. Spaces, punctuation and all other characters count toward the total.

An edited copy keeps the original format. Your source file stays untouched. The Mac app supports additional document formats.

Browser processing also uses wllama (MIT), hash-wasm (MIT), and fflate (MIT).

Built with llama.cpp (MIT), Gemma 4 / Google QAT GGUF (Apache-2.0), lxml (BSD), Python (PSF), and PyInstaller (GPL with distribution exception).
