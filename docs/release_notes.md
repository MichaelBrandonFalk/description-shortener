Description Shortener V1.0 is a self-contained, fully local Mac app for shortening descriptions to 110 characters or fewer.

Download the ZIP, unzip it, and drag the app to Applications. No API key or separate model installation is needed.

- Apple Silicon, macOS 14 or newer. 8 GB RAM minimum, 16 GB recommended.
- Pasted text, XLSX, CSV, DOCX, TXT, and macOS document conversions.
- Hard length/punctuation checks and a separate local-model meaning review.
- Unresolved descriptions block export; originals stay unchanged.
- Full open-source credits and licenses included.

This build is ad-hoc signed and is not Apple notarized. macOS may require Privacy & Security → Open Anyway on first launch. Semantic review uses a language model and is not a guarantee; review changed wording before use.
