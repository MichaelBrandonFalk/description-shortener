Supported files and processing
INPUTOUTPUT
Pasted textOnly shortened text, one description per line.
XLSX / CSVSame format. Description fields and long prose are processed; other values, headers and row order are retained.
DOCX / TXTSame format. Word body paragraphs and table text, or one description per TXT line.
RTF / DOC / ODTMac only. Same format through macOS conversion. Complex layout may change.
PDF with selectable textMac only. TXT. PDF layout and scanned-image OCR are not supported.

Shortening keeps the gist within the chosen character limit. Supporting details may be dropped. A “May need review” flag appears outside the output text. If the model fails, a flagged source excerpt is returned when possible. Review changed wording before use. Changed Word text uses its first run’s formatting, and changed Excel rich text retains its cell style.

Installation and requirements

Apple Silicon (M1 or newer), macOS 14 or later, and 16 GB RAM minimum. Allow about 25 GB free space during installation. Unzip the download and drag the app to Applications.

This release is ad-hoc signed and is not Apple notarized. If macOS blocks first launch, use System Settings → Privacy & Security → Open Anyway for Description Shortener.

Windows: extract the complete ZIP into a writable folder. Linux Mint 22.x / Ubuntu 22.04: install the downloaded DEB with your package installer or sudo apt install ./Description-Shortener-V1.4-Linux-x64.deb. Python and the model are bundled. The previews support pasted text, XLSX, CSV, DOCX and TXT. Tests run on Windows Server 2022 and Ubuntu 22.04 CI, plus official Linux Mint 22.3 Cinnamon userspace in a userspace container. A full booted Mint desktop is not covered; this is not a claim that every PC, GPU or Linux distribution is supported.

Privacy and source code

No API key, account, cloud processing or separate model installation is required. The model stays loaded while the app is open to speed up subsequent runs. Processing uses a private localhost connection, with no analytics or persistent input logs.
